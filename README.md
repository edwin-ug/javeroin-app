# Javeroin Seller App

A mobile-responsive web application designed for sellers to manage voucher inventory, track daily sales, and analyze revenue performance.

**Live Demo:** [javeroin-app.vercel.app](https://javeroin-app.vercel.app)

## Features

*   **Secure Access:** Dedicated seller login portal to protect inventory and sales data.
*   **Inventory Management (Store):** View available voucher codes, durations , and pricing in real-time.
*   **Sales History:** Track sold vouchers for the current shift, export reports to CSV, and seamlessly reset shifts.
*   **Performance Analytics:** Interactive bar charts displaying revenue and voucher sales over 7-day and 7-month periods.

## Tech Stack

*   **Frontend:** HTML, CSS, JavaScript
*   **Backend:** PHP
*   **Deployment:** Vercel
